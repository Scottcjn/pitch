# Contributing

Thanks for helping improve the Elyan Labs pitch materials. This repository is a
small static presentation site, so contributions should keep the deck readable,
easy to review, and safe to publish.

## Local Setup

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/Scottcjn/pitch.git
cd pitch
```

No build step is required for the current static files.

## What to Contribute

- Copy edits that make the pitch clearer
- Speaker note improvements
- Accessibility fixes in the HTML
- Small layout or style improvements that preserve the existing visual direction
- Broken link fixes

## Validation

Before opening a pull request, run:

```bash
git diff --check
```

For visual changes, preview `index.html` locally and mention the browser you
used in the pull request.

## Pull Request Checklist

- Keep the PR focused on one kind of change.
- Explain the audience-facing impact.
- Include screenshots for visual changes.
- Link the related issue or bounty, if applicable.
