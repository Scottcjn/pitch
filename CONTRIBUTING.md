# Contributing to Pitch

Thank you for your interest in contributing to Pitch!

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/your-username/pitch.git`
3. **Create** a branch: `git checkout -b feature/your-feature`
4. **Make** your changes
5. **Test** your changes
6. **Submit** a Pull Request

## Development Setup

```bash
# Clone and setup
git clone https://github.com/your-username/pitch.git
cd pitch

# Install dependencies
pip install -r requirements.txt
```

## Code Style

- Follow project-specific coding standards
- Use meaningful names
- Add documentation
